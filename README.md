# Dr. Mark D. Mosley - Professional Portfolio

This repository contains the source code for the professional portfolio of **Dr. Mark D. Mosley**. 
The website serves as a digital resume and business card, highlighting his extensive career in Data Science, Operational Excellence, and Academic Leadership, alongside his professional certifications and consulting services.

## Technologies Used
- **HTML5**: Semantic and accessible document structure.
- **CSS3 (Vanilla)**: Custom styling featuring a modern dark theme, sleek glassmorphism UI elements, and fully responsive layouts optimized for Desktop, Tablets (iPad), and Mobile.
- **JavaScript (Vanilla)**: Lightweight interactions, including native-feeling touch-swipe carousels, animated statistical counters, and smooth scrolling capabilities.

## Local Development
To run this website locally on your machine for editing or previewing:
1. Clone this repository to your local machine.
2. Open `index.html` directly in your preferred web browser, or serve it using a local development server (e.g., VSCode Live Server, Python HTTP server). No complex build steps or installations (like Node.js) are required.

## Deployment to GitHub Pages
This website is built as a static site and is ready to be hosted natively via **GitHub Pages**. 
1. Push the code to the `main` branch of this repository.
2. Go to the repository **Settings** > **Pages**.
3. Under "Build and deployment", set the Source to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click Save. 
5. GitHub will automatically build and host the site!
